# LungCancerAI

A Multimodal Explainable Deep Learning Framework for Lung Cancer Classification and Stage Prediction using CT Images and Clinical Data.

## Features

- CT preprocessing
- Clinical preprocessing
- MedicalNet
- Clinical MLP
- Multimodal Fusion
- Explainability
- Streamlit Deployment

## Dataset

NSCLC-Radiomics

## Framework

PyTorch + MONAI
